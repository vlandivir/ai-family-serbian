# Сербский

Правила наставника по сербскому для семейного бота. Репозиторий публичный, секретов и семейных переписок в нём нет.

Очередь, Telegram и привязка темы живут в [`vlandivir/ai-family`](https://github.com/vlandivir/ai-family). Воркер перед ответом обновляет эту копию и запускает в ней агента. Как отвечать — в `AGENTS.md`.

Язык ответов — экавица, как говорят в Белграде. В переписке фраза даётся латиницей, следом та же фраза кириллицей.
